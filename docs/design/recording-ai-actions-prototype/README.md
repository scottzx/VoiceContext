## 走查路径

1. 已有会议列表 → 录音详情（四内容 Tab / 更多菜单 / 固定底部播放器）→ 更多操作 → 交给智能体 → 范围 / 模板 Sheet → 原聊天输入区。原发送按钮才执行；运行继续在原会话。画布外「演示：提交整理结果」模拟校验后完成提交。
2. 原「智能体产物」Sheet → 文件 List → 系统文档预览示意；新增最小来源 / 行动信息子页区分明确决策 / 讨论建议 / 未决项。普通文件沿用 QuickLook，不另造富文本阅读器；历史文件不编造来源版本与完成状态。
3. 行动建议默认不勾选：编辑账户 / 列表、独立到期 / 定时提醒 → 勾选 → 核对精确内容 → 一次确认。三项示例依次返回成功、保存前失败、保存后待核实；分别重试失败或核实回执。
4. 详情更多菜单 → 重新转写 / 分析 → 预检 → 候选比较：默认保留人工校对，整份替换另行确认；音频过期禁用生成，取消保留旧稿。
5. 回到会议列表，从录音行菜单打开原删除确认的扩展范围：显示受管原文 / 全部快照与版本清理、派生结果默认删除、系统事项保留；可明确保留摘要 / 导图。来源删除后回跳与未确认创建禁用。部分清理失败可继续。
6. 已创建项 → 现有待办编辑表单，尾部补来源关联；日期总览与「全部」继续沿用原页面，无日期事项归未安排。
7. P1 导图：折叠树 / 文字等价阅读、节点来源、行动建议入口、两种示例导出；无自由画布。

场景切换提供正常、处理中、部分可用、旧文稿完整性未记录、已创建但系统设置有差异、正常静音、有声空识别、音频过期、无模型、无文字、离线、来源更新、运行中断、格式校验失败、权限、只读、无效日期、系统外部修改 / 删除、来源删除、清理失败、无效导图。场景选择只方便评审，不代表这些 iOS 状态已实现。

- 使用 browser-skill 在专属 Edge Agent Window 中实际点击：整理 Sheet → 指定来源范围 → 固定版本 12 草稿 → 发送 → 处理中 → 演示提交 → 结果。
