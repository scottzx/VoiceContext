# 拓展方块与自定义功能

日期：2026-10-09。依据：产品负责人本次对话明确要求拓展每行四个方块、顶部新增自定义功能、URL 与可选 Logo 配置、首字回退和长按调整。

拓展首页按「自定义功能 → 助手能力 → 工具连接 → 工具 → 我的与设置」排列。现有板块及内置入口顺序保留。自定义功能末尾始终有「添加」入口；空状态只显示添加入口。默认调整范围为自定义功能，不删除或重排内置能力。若产品负责人选择所有入口排序，需另行调整此范围。

## UI/UX 风格

复用已确认的 `DESIGN.md`：原生安静工具、系统字体、黑白灰、20 pt 页边距、24 pt 板块间距、12 pt 控件圆角、至少 44 pt 点击范围。此次用户明确指定拓展首页使用四列方块，替代该页原有平铺列表；其他页面继续遵守原规范。Logo 可保留用户上传图片的颜色，不为内置功能分配装饰色。名称放在方块下方，允许多行和动态字体。

无需独立原型；新增及编辑使用原生 Form，长按直接进入原生调整列表。另提供「管理」按钮和 VoiceOver 调整动作。调整页支持拖动排序、删除确认、点按编辑，并提供 VoiceOver 上移、下移、删除动作。删除只移除入口，不影响远端服务。

## 配置与打开

- 必填名称和完整 HTTP/HTTPS URL；URL 可包含固定端口、路径和查询参数。仅修剪前后空白，不改变端口、路径或查询内容；非法地址和空名称不能保存。
- Logo 可从照片或文件选择，导入时按最长边 256 px 缩小为 PNG，保留透明度。没有图片时显示名称第一个完整字符，英文字母转大写。
- 点击入口全屏打开单个应用内网页，仅保留名称和原生「返回」按钮，不显示浏览器标签页、地址栏、历史前进后退控件或应用 Tab。返回直接退出页面，不回退网页历史；网页新窗口链接在当前页面打开，网页主动关闭窗口也退出页面。使用独立临时浏览器池，复用现有浏览器内核、登录 Cookie、失败重试和全局资源上限；退出停止加载及音视频采集，关闭临时页面。普通浏览器入口保持原有标签页界面。浏览器容量受限时显示错误和重试入口。与原全局浏览器相同，此页面没有聊天会话下载目录，不新增下载能力。
- localhost/127.0.0.1 指 iPhone 本机。电脑服务须填写电脑局域网 IP 或 Tailscale 主机名/IP 与端口。连接、系统局域网授权与 HTTPS 证书由现有网络和浏览器机制处理。

不新增后台服务管理、服务发现、端口扫描、Tailscale 连接管理或证书绕过。

## 数据与失败状态

配置保存在当前应用的 `Application Support/Yima/custom-extensions.json`；界面不自动上传配置。Agent 主动调用下述原生命令时，结果会返回名称、URL、顺序和图标状态，不返回图片字节。JSON 数组顺序即首页顺序；每项含稳定 UUID、名称、URL、可选 Logo 数据。开发版与正式版各用自身容器。新增、编辑、排序、删除先原子写入成功再更新界面。

导入或保存失败显示原生错误提示，保留已填信息；已有配置读取失败时保留原文件、展示错误并禁用添加，避免覆盖原数据。未选择 Logo 可直接保存。

## Agent 原生 CLI

2026-10-09 追加要求：像现有 Apple 工具一样，提供 Agent 可调用的原生命令管理自定义功能配置。采用 `yima-extensions`，复用现有 `shell_execute → iSH native offload → Swift` 调用链和 `CustomExtensionsStore.shared`。不通过 shell 直接改 JSON，不建立另一份配置数据。

```sh
yima-extensions --help
yima-extensions list --compact
yima-extensions get --id <uuid>
yima-extensions add --name '我的工作台' --url 'http://100.101.102.103:3000/workspace'
yima-extensions update --id <uuid> --name '新名称' --url 'https://mac.tail123.ts.net:8443/'
yima-extensions update --id <uuid> --clear-logo
yima-extensions move --id <uuid> --position 0
yima-extensions delete --id <uuid>
```

`list/get` 返回稳定 ID、名称、完整 URL、从 0 开始的最终位置 `position`、`has_logo` 和首字 `initial`。新增未上传图片时用首字回退；普通更新保留已有 Logo，只有显式 `--clear-logo` 才清除。删除只删除入口。CLI 与界面共用校验、原子保存和可观察数据，命令成功后界面立即反映修改。参数缺失、重复、不适用于当前命令或 URL/位置非法时，返回错误且不修改配置。

编辑表单保存时核对打开时的配置快照。若 Agent 已修改该入口，拒绝过期保存并提示重新打开，避免用旧 URL 或 Logo 覆盖较新的修改；单纯排序不会阻止编辑。

复用 Apple 工具的 JSON 信封、`--compact`、`-q/--quiet` 和退出码：成功 0、一般/不存在错误 1、参数错误 2、不可用 4；`--help/-h` 向 stderr 输出帮助并返回 0。权限入口加入现有工具权限管理，使用其 Bypass / Ask Once / Not Allowed 策略。Agent 指引要求按用户授权修改配置。该能力仅在融合版注册、打包和提示；独立 Minis 构建不引用融合数据层。

此阶段的 CLI 管理功能入口配置；不将任意 URL 自动转换为产品业务 API，也不执行远端产品的任意命令。需要打开或操作网页时，Agent 可以读取该 URL 后使用已有浏览器工具。

## 验收

1. 首页所有入口每行四个；自定义板块在顶部；原有板块和入口顺序、导航及设置恢复逻辑保留。
2. 添加 localhost、局域网与 Tailscale URL，可保留端口、路径及参数；保存后立即出现，重启仍在。
3. 图片可选，导入错误能继续修改；中文、英文和组合字符正确显示首字回退。
4. 点按全屏打开指定 URL，不显示浏览器标签页和地址栏；返回直接关闭页面，网页新窗口链接不增加标签页。长按只进入调整页，不同时打开网页。调整顺序及删除在重启后保持，其他配置不变。
5. 删除先确认；写入失败不丢失现有入口；无效 URL 不可保存。
6. 深浅色、动态字体及 VoiceOver 使用共享设计语义；设备视觉和交互验收待用户授权后进行。禁止模拟器。
7. Agent CLI 可查询、新增、编辑、调整顺序和删除同一批功能；更新保留未修改字段和 Logo；非法参数、损坏配置或写入失败不改变现有配置；融合版工具权限和原生注册完整。
