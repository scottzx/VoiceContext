# 美食地图可点击原型

设计依据：[美食地图首版设计](../food-map.md)与[项目设计规范](../../../DESIGN.md)。日期：2026-10-20。

用户已确认从“拓展”进入，在 Yima 内使用手机原生地图，地点和标签保存在 Yima；首版由用户提供具体店名或地址，苹果地图承接导航。本原型用于评审地图、收藏列表、标签与地点详情，不代表最终布局已经确认或原生功能已经实现。

入口：[index.html](./index.html)。本机预览服务运行时可打开[可点击预览](http://127.0.0.1:4194/food-map-prototype/)。本目录为无构建依赖的本地 HTML/CSS/JavaScript，可整体复制；`127.0.0.1` 地址只用于当前电脑查看。

## 评审路径

1. 默认进入美食地图；切换“地图 / 收藏”，观察同一批地点的两种展示。
2. 选择“想去”“面食”等标签，并输入店名或地址；核对地图标记、列表和结果数量一致。清除筛选可恢复全部。
3. 点地图标记或收藏行，打开同一份地点详情，查看完整地址与标签。
4. 编辑标签，分别尝试保存和取消；保存后在列表和筛选中核对结果。
5. 点添加，通过文字演示口述内容、选择具体分店、设置标签并保存；查看新地点出现在地图和收藏列表。
6. 在详情点“苹果地图导航”，观察导航交接演示；该按钮不会开启真实导航。
7. 返回“拓展”，从“工具”区的“美食地图”重新进入；一级页显示四个 Tab，地图页隐藏主 Tab。
8. 使用 App 画布外的评审控制查看深浅色、大字号、空收藏、网络和定位受限；可恢复默认演示。

## 原型边界

- 地图是本地 SVG 地理示意，店名、地址、候选分店与地点位置均为虚构。地点名称和空间分布不用于现实查店或导航。
- 底图中水体、公园的淡色用于地理语义；应用控件、标签与选择状态遵循原生单色方向。
- 口述使用文本模拟，不采集麦克风、不请求定位、不调用模型或地图查询服务。演示候选与回执不构成真实搜索/保存/导航的验收证据。
- 收藏更改仅保存在当前浏览器的演示存储中，与 iPhone 上的 Yima 数据分离。重置只作用于这份原型数据。“空收藏”开关使用独立临时演示数据；关闭后恢复原收藏，不会清空原型的已存地点。
- 桌面侧边或窄屏下方的状态评审控制不属于产品界面；其他拓展能力只演示入口位置。
- 浏览器键盘与字号评审不能替代 iOS Dynamic Type、VoiceOver、真实地图手势和系统导航交接的真机验收。本轮不运行 iOS App 或模拟器。

## 验证记录

2026-10-20，使用 Codex 内置浏览器实际点击并保存截图：

- “想去”筛选后地图显示 3 个标记，收藏列表显示相同 3 个地点；继续搜索“河畔”剩 1 个地点。
- 自由标签“周末去”可新增并保存；取消编辑不写入。刷新后仍能看到已保存修改。
- 添加流程在未选择分店时不能继续；明确口述的自定义标签能进入保存步骤，未说标签时不会因店名含“咖啡”而擅自打标签。
- 新增收藏从 5 条变为 6 条；重复保存同一地点合并标签，删除确认后回到 5 条。连续新增两个不同店名可在地图分别点选，不再覆盖同一个演示标记位置。
- 返回拓展后可从工具区重新进入；原型在拓展显示四 Tab，在美食地图隐藏主 Tab。键盘 Tab / Shift+Tab 在弹层内循环，Escape 关闭，切换地图/收藏后焦点保留。
- 空收藏有添加入口；网络不可用时仍显示收藏，查找保留输入、导航说明不可用；定位不可用时仍能管理收藏。
- 在 320×740 CSS 视口核对深色、大字号和标签编辑，无页面横向溢出，所有可见按钮至少 44×44。内置浏览器常规预览面板中地图与底部操作可完整显示；标签超出宽度时横向滚动。
- 浏览器未记录到原型脚本错误。JavaScript 语法、文档链接和差异空白检查通过；存储失败回执经过静态复核，未做浏览器配额耗尽注入测试。
