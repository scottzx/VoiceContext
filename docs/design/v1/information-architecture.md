# VoiceContext v1 信息架构

> PM `#39` 交付物 · 版本 0.3 · 2026-08-13
>
> 本版本落实产品负责人确认：**Recording 是唯一记录对象；会议是可选结构化模式；所有原始音频默认保留 7 天，用户可逐条开启长期保留。** 来源：[`docs/PRD.md`](../../PRD.md) 第 8–11、14–16、19 节。
>
> **2026-08-13 IA 增量（`#64` / FR-ADD-IA-*）**：默认首页改为「全部录音列表 + 搜索 + 录音主按钮 + 导入」；日历降为列表上方可选日过滤工具，不再作为唯一首页心智模型。详见 [`ia-home-list-first-note.md`](ia-home-list-first-note.md)。

## 核心决策

- 用户只需理解“开始记录”，不必在录音前判断自己属于会议或日常收音。
- `isMeeting` 不是录音类型、Tab、列表或处理链路。它只显示并保存三个可选字段：会议主题、参与人、议程文本。
- 全量录音列表是默认首页浏览结构。默认按日期从新到旧分组显示全部 Recording；顶部搜索框检索离线转写；时间筛选菜单与日历日条是列表上方工具，用于缩小范围，而不是唯一首页。
- 左上角「导入」与底部红色录音主按钮是并列主路径入口；较长静音形成记录内片段，不创建第二种可见记录对象。
- “我的”从右上角进入，承载设置、购买、同步、保留策略、Skill、隐私与许可；主页面不保留底部多 Tab。
- 录音条是全局入口。无论用户在列表、日历过滤、详情或“我的”，录音状态、时长、待处理数与停止操作始终可见。

## 页面树

```text
VoiceContext
├── 首次引导
│   ├── 本地与隐私说明
│   ├── 麦克风权限
│   ├── iCloud 文本同步 / 加密声纹同步选择
│   └── 60 分钟试用说明
│
└── 全部录音（唯一主页面）
    ├── 导航栏：导入菜单（文件 / 照片与视频）· 标题「全部录音」· “我的”
    ├── 列表工具区：转写搜索、时间筛选、日历日过滤（可选，「全部」为默认）
    ├── 按日期分组的全量记录流
    │   ├── 空状态 / 有记录 / 搜索结果 / 录音中 / 处理中 / 需要注意
    │   └── Recording 详情
    │       ├── 本地音频回听、逐字稿、片段、说话人确认
    │       ├── 标题、标签、参与人、长期保留
    │       ├── 可选会议结构：会议主题、议程文本
    │       └── 导出 MD / JSON、派生纪要状态
    ├── 底部：录音主按钮（capture dock）
    ├── 开始记录 sheet
    │   ├── 直接开始
    │   └── 这是一次会议（可选）
    │       └── 会议主题、参与人、议程文本
    ├── 录音中 / 停止确认 / 处理中
    └── 我的
        ├── 试用额度、永久解锁、恢复购买
        ├── iCloud 文本同步、加密声纹同步
        ├── 音频保留与存储清理
        ├── Skill 说明与本地导出
        ├── 隐私说明
        └── 第三方许可与归因
```

## 导航规则

| 区域 | 入口与去向 | 返回 | 必须保持的语义 |
|---|---|---|---|
| 全部录音首页 | 启动后默认进入；搜索转写、打开记录、开始录音、导入、打开“我的” | 无栈返回 | 默认展示全部列表；日期分组是浏览层级；日历/时间筛选是可选工具，不阻塞主路径 |
| 开始记录 | 主页面底部录音主按钮 | 取消回全部列表（或当前日过滤） | 直接开始可用；会议开关和字段完全可选，随时可补充 |
| 录音中 | 开始记录或全局录音条 | 离开不停止录音 | 显示时长、电平、状态、已转写至、待处理数与直接停止入口；每约 60 秒增量处理已关闭分片 |
| 停止与处理 | 点击停止后 | 可返回详情或开始新 Recording | 安全关闭最后分片后立即释放麦克风；剩余处理继续，不以空文本表示完成 |
| 记录详情 | 全部列表、搜索结果、处理完成或全局状态 | 回全部列表（保留当前过滤） | 同一详情同时容纳普通记录和可选会议字段 |
| 我的 | 主页面右上角 | 回全部录音首页 | 同步不可用不阻塞本地记录、处理、编辑和导出 |

## Recording 字段

| 字段 | 默认 / 必填 | 说明 |
|---|---|---|
| `recordingId`、开始时间、处理状态 | 系统生成 | 任何记录均有；状态为 recording / processing / complete / needs_attention 等 |
| 标题、标签、参与人 | 可选 | 可在开始前、录音中或结束后填写；多人对话不限于会议 |
| `isMeeting` | 默认 false | 仅控制会议结构化字段和会议纪要入口，不改变录音或保留策略 |
| 会议主题、议程文本 | `isMeeting=true` 时可选 | 议程 v1 仅为纯文本输入；不上传或附加实体文件 |
| 记录内片段 | 系统生成 | 较长静音形成的阅读与定位单位，不是新 recording 或新麦克风会话 |
| 长期保留 | 默认 false | 所有原始音频默认 7 天；开启后不自动清理，会议不会自动开启 |

## 全局录音条

| 状态 | 需要显示 | 操作 |
|---|---|---|
| `preparing` | “正在准备记录” | 取消 |
| `recording` | 红色状态、时长、电平、已转写至、待处理数量 | 打开当前记录、停止 |
| `paused` | 已暂停与已录时长 | 继续、停止 |
| `interrupted` | 中断时间、gap 和影响 | 打开当前记录、停止 |
| `stopping` | 正在安全保存最后分片 | 等待，禁用重复停止 |

## 范围护栏

统一模型不引入 iPad、Mac、Windows、输入法、电话录音、其他 App 系统音、云端 ASR、内置 LLM、自动监听或原始音频 iCloud 同步。`generate-meeting-minutes` 只可用于 `isMeeting=true` 且 `state=complete` 的记录；普通记录仍可导出开放文档，但 v1 不提供日历搜索 Skill。
