# 首页 IA：列表优先（FR-ADD-IA-* / #64）

> 轻量走查备注 · 2026-08-13 · 可附 `#41`

## 变更摘要

默认首页从「日历选日 → 当日列表」收敛为：

1. **全部录音列表**（按日分组，新到旧）
2. **转写搜索**（离线，不回归 #63）
3. **录音主按钮**（底部 capture dock）
4. **导入入口**（导航栏左侧：文件 / 照片与视频）

日历日条与时间筛选菜单保留在列表上方，作为**可选过滤工具**；默认选中「全部」，不作为唯一首页心智模型。

对应条款：`FR-ADD-IA-001`、`FR-ADD-IA-002`、`FR-ADD-IA-003`（见 `docs/PRD-consumer-parity-addendum.md` §5.8）。

## 轻量走查清单

| # | 步骤 | 期望 |
|---|---|---|
| 1 | 冷启动进入主页 | 标题为「全部录音」；未选具体日期时直接看到全量（或时间筛选范围内）列表 |
| 2 | 观察顶部工具区 | 搜索框、时间筛选、日历「全部」芯片可见；日历带「按日期过滤」语义 |
| 3 | 点某一天 | 列表收窄到该日；空日显示「这一天还没有记录」，并提示可回「全部」 |
| 4 | 再点「全部」或已选日期 | 清除日过滤，回到全量列表 |
| 5 | 输入转写关键词 | 搜索结果替换列表；日历条隐藏；清空搜索后列表与过滤状态可恢复 |
| 6 | 左上角导入 / 底部录音钮 | 导入菜单与录音主按钮仍是主路径，不依赖先选日期 |
| 7 | 进入「我的」再返回 | 回到全部录音首页，而非被迫落在某一日历日 |

## 非目标

- 不做 Share Extension
- 不重做底部多 Tab
- 不回归离线转写搜索（#63）
