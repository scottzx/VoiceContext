# VoiceContext v1 状态矩阵

> PM `#39` 交付物 · 版本 0.3 · 2026-08-07
>
> `Recording` 是唯一对象。会议开关只控制结构化字段，不能创建第二套页面、状态或保留策略。

| 页面 / 区域 | 正常与空状态 | 关键异常 / 生命周期状态 | 必须操作 |
|---|---|---|---|
| 本地与隐私、麦克风权限 | 首次说明本地处理；拒绝权限后仍可浏览 | 权限拒绝：解释用途、提供去设置 | 继续、暂不允许、去设置 |
| 同步与试用引导 | 两类同步开关独立；额度可用 | iCloud 未登录 / 空间不足；试用临界 / 耗尽 | 跳过同步、购买、恢复购买 |
| 日历记录页 | 空：开始第一条记录；有内容：按日期显示所有记录 | `recording`、`processing`、`needs_attention` 均在同一流中可辨 | 选日期、开始记录、打开记录、打开“我的” |
| 开始记录 | 空表单可直接开始；可补标题、标签、参与人 | 权限受限、低存储；会议开关展开主题 / 议程文本 | 开始、取消、设为会议；字段可稍后补充 |
| 录音中 | 时长、电平、分钟级增量文稿、“已转写至”和待处理数 | 后台积压、热暂停、暂停、中断 gap、路由变化 | 暂停、继续、停止；任意页面通过全局条返回 |
| 停止与处理中 | 安全关闭最后分片后立即释放麦克风；显示剩余处理阶段与待处理数 | 后台暂停推理、热状态、转写失败、试用锁定 | 开始新录音、稍后查看、重试、购买 |
| Recording 详情 | 音频可用、逐字稿、标签、参与人、revision、导出 | 音频已清理但文档可读；processing / needs_attention | 编辑、播放、保留、导出、说话人确认 |
| 会议字段（详情内） | `isMeeting=false` 时隐藏；开启后显示主题、参与人、议程文本 | 字段为空不阻止记录或处理；complete 前 Skill 不可用 | 开启 / 关闭会议结构、编辑字段 |
| 记录内片段 | 按绝对时间阅读；可命名、加标签 | 音频临近到期 / 已清理、处理失败 | 打开、编辑、设置长期保留 |
| 说话人确认 | unknown 显示“说话人 N”；confirmed 显示确认名 | suspected 明示“疑似”；候选重叠不自动确认 | 重命名、确认、否认、保持未知 |
| 导出与 Skill | 本地 MD / JSON 总可导出；会议且 complete 可使用 Skill | iCloud 不可用 / 冲突仍使用本地 Documents | 分享、存储到文件、重试同步；Skill 只派生写入 |
| 我的 | 同步、保留、购买、Skill、隐私、许可入口 | iCloud 不可用、密钥问题、存储不足、商店离线 | 进入对应设置；不阻塞本地记录 |
| 第三方许可 | 离线可读 | 不依赖网络、账号或 iCloud | 浏览许可与归因 |

## 跨页不变量

1. 所有录音路径显示同一个全局录音条和立即停止入口。
2. 所有记录的原始音频默认 7 天；会议标记不改变默认，用户可按记录或片段长期保留。
3. 所有记录均可填写参与人、标题与标签；会议只额外提供主题、议程文本和会议纪要入口。
4. `recording`、`processing`、`complete`、`needs_attention` 依靠文字、图标和操作区分，不只依赖颜色。
5. iCloud 关闭或失败时，录音、处理、编辑与 Files 导出完整可用。
6. `recording` 与 `processing` 可以同时成立；处理状态不能覆盖录音状态或阻止当前/下一条 Recording 使用麦克风。
7. 前台只宣称分钟级增量转写；后台、热暂停或积压时显示事实与数量，不宣称严格实时。
