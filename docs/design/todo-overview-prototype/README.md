# 待办事项双组件原型

设计依据：[`../todo-overview.md`](../todo-overview.md) 与 [`../../../DESIGN.md`](../../../DESIGN.md)。

打开本机预览：`http://127.0.0.1:4175/todo-overview-prototype/`。

服务器停止后，在仓库根目录执行：

```sh
python3 -m http.server 4175 --bind 127.0.0.1 --directory docs/design
```

原型包含月历／周历、左右滑动翻页、日历右上角“今天”、红色待办点／绿色日程点、日期切换、当天待办与日程、完成示例待办、全部事项列表、系统日历与待办来源列表多选、返回恢复首页上下文、深浅色及空／未授权／失败展示。所有数据均为虚构示例；关闭或刷新重置，不读写 EventKit。新增与编辑入口仅说明正式版将复用的原生表单，不模拟完整系统编辑器。Tab 图标为网页占位，不作为 SwiftUI 图标方案。

验证记录（2026-10-01）：

- `node --check app.js` 通过。
- Edge 浏览器 393×852 CSS 视口深浅色截图经过视觉检查。
- 日期从10月1日切到10月2日，待办与日程同步变更。
- 历史验证（现已移除全部页日历视图）：原型曾支持全部页日期切换并在返回时恢复首页日期。新版保留返回恢复首页上下文。
- 完成一项示例待办后，当日待办数量与日期可访问描述同步从2变1。
- 日历未授权时显示独立授权说明，当日待办保持可用。
- 该视口所有手机画布内按钮命中区域 ≥44×44 CSS px，无横向溢出。
- 本次增量：10月1日／2日同时显示红色待办点与绿色日程点；9月30日仅红点，10月6日仅绿点，图例明确区分两类。
- 历史验证（现已改为来源勾选）：原型曾支持类型切换和待办列表单选，现用日历／待办两组多选替代。
- 筛选预览截图为 `preview-filter.png`，以2026-10-02最新的日历／待办来源多选方案为准。
- 日历交互更新（2026-10-02）：右上角仅保留“今天”文字入口，移除前后翻页按钮和事项区重复入口。浏览器合成指针事件验证左／右滑翻月、翻周，短距离／纵向／取消手势不翻页，滑动不误选日期；实际点击“今天”恢复演示当天，并保留月／周展开状态。原型仍固定以2026年10月1日为演示“今天”。

- 全部页更新（2026-10-02）：移除日历组件、时间／日历切换和类型下拉；筛选改为“日历列表／待办列表”两组勾选，可跨组多选。浏览器实际点击验证：取消个人列表隐藏个人待办但保留日程，取消工作日历只隐藏该来源日程，可只保留节假日；全部取消显示“尚未选择列表”，返回首页仍展示完整今日事项。截图：`preview-all.png`、`preview-filter.png`。

边界：网页不是 iOS 实现；未运行 App、真机或模拟器。真实权限、EventKit 时区／全天／跨日、Dynamic Type、VoiceOver、通知和外部同步仍待工程与真机验收。原型完成操作即时移出列表；正式版按设计说明提供成功反馈后再隐藏。日历与待办来源列表使用虚构示例，真实权限和读取仍待实现。看板服务离线，未创建任务、里程碑或改写功能蓝图。
