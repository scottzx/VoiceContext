## 严重级别定义

| 级别 | 含义 | 关闭门槛 |
|---|---|---|
| **blocker** | 阻断发布：录音安全感缺失、停止不可达、状态谎报、关键无障碍不可用、对比严重失效 | 必须修复并复验通过 |

## A. 首页日历记录流

**步骤**

1. 冷启动进入记录首页；观察大标题、「我的」、日历条、记录行、底部开始录音入口。
2. 空状态与有内容状态各看一次；确认个人/会议共用平面行，无彩色「闪击胶囊」卡片。
3. 横向滑动日历条并切换日期；确认筛选只改列表，不改变 Recording 主对象模型。
4. 有进行中录音时，确认全局录音条出现在内容顶部且可到停止。

**检查点**

| A1 | 单一「开始录音」入口清晰；无底部多 Tab | ☐ | | | | |

## B. 会议创建

**步骤**

1. 点开始录音 → sheet：可不填字段直接开始。
2. 打开「设为会议」，出现主题/议程文本；无附件控件。
3. 填写标题、参与人、标签（均可选）后开始一条短会议录音并停止。

## D. 录音中 / 暂停 / 停止

**步骤**

1. 开始录音：立即显示录音中；红点/状态与处理态不可混淆。
2. 暂停 → 继续；确认文案、图标、触控反馈。
3. 停止：底部拇指区停止入口；停止后麦克风/chrome **立即**释放。
4. 录音页可「最小化」回首页；全局条仍提供停止。

**检查点**

| # | 检查项 | Pass | blocker | major | minor | 证据 |
|---|---|---|---|---|---|---|
| D1 | 录音视觉标识持续可见，不与 processing 混淆 | ☐ | | | | |
| D2 | 暂停/继续/停止集中在底部可达区；停止不藏二级菜单 | ☐ | | | | |
| D3 | 时长为可读无障碍值（如「12 分 48 秒」），非逐字噪声 | ☐ | | | | |
| D4 | 停止后可立刻开始新 Recording | ☐ | | | | |
| D5 | 电平/脉冲在普通模式可接受；不遮挡停止 | ☐ | | | | |

## F. 处理中与失败恢复

**步骤**

1. 停止后或录音并行时观察 processing：阶段/待处理数/「已转写至」。
2. 制造或等待失败：确认「转写未完成，音频已保存」+ 重试；无空完成稿。
3. 旧 Recording processing/failed 时开始新录音：互不抢麦。

**检查点**
