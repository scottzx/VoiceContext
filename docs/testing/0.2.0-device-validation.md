## 自动化已覆盖（无需真机复跑逻辑）

下列项已在模拟器单测/集成测建模；真机只做抽查确认，不必当作首次证明：

- 全局 SenseVoice Metal 并发上限 = 1（`InferenceLifecycleGate` / 共享 gate）
- 同一 Recording 的 chunk jobs 按 `startSample` 顺序执行
- 停止后立即释放 capture chrome；旧 Recording 的 processing/failed 不占用麦克风
- 新 Recording 可在旧 Recording processing/failed 期间开始；jobs / segments 隔离
- thermal defer 不提交 Metal、不把 job 标 failed，且不阻止新 capture
- transcript `source_ranges` 边界/seek/error locate、幂等重试无重复 segment
- 25s 连续语音硬上限、跨 chunk carry、短语音与 gap 终止 carry（单元级）
- 历史非 60 秒（含 5 分钟）chunk 样本范围可读、可入分析边界

## A. ≥2 小时录音 + 分钟级增量转写（主路径）

**步骤**

1. 显式开始一条新 Recording；确认 UI 立即显示录音中，且「开始」入口因麦克风占用不可再点。
2. 连续录制 ≥2 小时，期间保持有人声（可朗读/对话）；允许短暂停顿，但不要整段静音。
3. 录音未停止时，每约 5–10 分钟抽查详情/主界面：
   - 文本在前进（「已转写至 +MM:SS」或等价文案单调不回退）
   - 待处理项在前台应被消化；积压时仍可继续录音
4. 停止录音：确认麦克风/录音 chrome **立即**释放（可马上开始下一条），无需等待转写完成。
5. 停止后等待队列清空；导出或打开文稿，核对约 120 个完整 60s chunk + 可选尾段。

**通过条件**

- [ ] 无掉录/无长时间静默丢片（听感与 chunk 索引一致）
- [ ] 分钟级文本持续前进；停止前至少观察到多次「已转写至」推进
- [ ] 停止后麦克风立即释放，可立刻开始新 Recording
- [ ] chunk 边界连续；未解释缺口必有 gap；完整性诊断无未入索引 AAC

## C. 双 Recording 隔离与恢复

**步骤**

1. 录一条短录音并停止，使其处于 processing 或故意 failed。
2. **不要**等待其完成：立即开始第二条 Recording。
3. 第二条录音期间，观察第一条的 processing/failed/retry 不影响第二条的麦克风与主状态。
4. 对第一条执行重试（若 failed）；确认不抢走麦克风、不写入第二条的文稿。
5. 停止第二条；确认 chrome 立即释放；两条文稿/jobs 互不污染。

**通过条件**

- [ ] processing/failed/积压都不阻止新 Recording 开始/停止
- [ ] 重试旧 Recording 不借用新麦克风会话
- [ ] 无跨 Recording 的重复 segment / 错绑 chunk
- [ ] 强制终止（可选加测）：重启后不重复 job/segment，且不秘密开麦

## D. Metal 并发、顺序、去重与 source_ranges seek
