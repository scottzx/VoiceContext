# 美食地图实施检查与真机验收

日期：2026-10-20。范围依据：[已确认设计与接口契约](../design/food-map.md)。产品负责人已认可可点击原型并授权原生开发；本记录区分代码检查与设备体验验收。

## 已接入的功能

- 拓展 → 美食地图：原生 MapKit 底图、可点选的带名称标记、地图/收藏切换、店名/地址查找及标签筛选。
- 添加地点：真实地图搜索、可选城市/区域、完整地址候选选择、标签选择与新建、保存。查找不自动收藏；标签可不填，每项最多 12 个字符。
- 地点详情：完整地址、当前标签、标签编辑、带确认的删除，以及交给苹果地图选择路线。
- 本地收藏：当前应用 `Application Support/Yima/places.json`，原子保存、稳定 ID、版本检查、保守去重和合并标签；写入失败不发布成功，损坏或不支持版本的文件保留并禁止覆盖。
- 聊天与小蓝：`yima_places` 查询真实地点、读写同一收藏库、展示临时结果/已存地点及发起苹果地图交接。收藏须在当前页面的原生核对窗口点击“确认收藏”，取消不保存。普通主聊天在完整工具模式可用；小蓝已有语音入口无需另开页面。会议助手、子 Agent 和完成通知回合不能使用本工具。
- 页面展示使用现有 App 导航的页面版本及真实可见回执。编辑 Sheet 暂停小蓝收音；只读详情可由语音导航关闭，页面切换等待实际关闭完成。前后台、解锁和小蓝执行/导航代次继续由现有策略控制。

搜索不请求定位，不猜测当前城市；地址不足或多分店由用户补充/选择。候选只来自当前会话最近一次 MapKit 查询，30 分钟过期，不能用模型编造的名称和坐标直接创建收藏。保存后搜索候选解析到真实收藏 ID；跨入口修改标签会反映到同一地点，删除后不回退为未收藏候选。

只保留 MapKit 原始坐标用于地图显示和苹果地图交接，不导入旧 `apple-maps` / `apple-location` 输出，不猜测 WGS-84/GCJ-02 转换。网络搜索、地图底图、导航和模型语音仍依赖各自服务；本地收藏列表可独立读取。苹果地图接受目的地只表示 `handoff_accepted`，不等于用户已开始导航。

## 收藏确认修正检查（2026-10-20）

真机试用反馈定位到两个原因：Agent 明确收藏指令会直接写入，且搜索展示只按来源写“待选地点”，没有反映实际已收藏。不存在隐藏的对话确认窗；之前对用户的操作说明只适用于手动添加，不适用于小蓝路径。用户现已明确选择先弹窗核对，再点确认保存。

修正内容：

- `save` 等待 `YimaPlacesSaveConfirmation`，只有真实出现的原生弹窗“确认收藏”按钮可提交写入；成功回执带 `confirmed_by=native_button`。模型不能传一个布尔参数跳过确认。
- 当前页面展示名称、完整地址与最终合并标签，取消不写入；失败保留弹窗与输入，标签变化刷新后需再次确认。候选、当前执行及取消状态在确认按钮事件中重新核验。
- 未出现的弹窗 8 秒结束，已出现的确认最多等待 90 秒；外层语音执行可能更早取消。退出前台、锁定、候选被新查询替代或执行失效均取消未提交的收藏，不自动重复弹窗。
- 弹窗关闭前禁止抢页；等待实际关闭后再恢复原页面及此前仍有效的语音导航绑定。关闭回调异常迟到时，保留已挂载弹窗的所有权阻止新请求，避免旧回调取消新请求。
- 确认期间只停止小蓝监听，不使用会取消执行的普通暂停；待确认工具继续等待，取消/确认关闭后按现有状态恢复。锁屏/后台取消后重新回前台重挂实际页面，不重新授予旧请求的导航权限。
- 地图搜索分段称“地图/列表”，来源称“搜索结果”；地图、列表行与工具回执按共享收藏库实时反映已收藏/未收藏及数量。保存后如需展示该收藏，优先使用返回的真实 `place_id`。

## 语音演示顺序

1. “小蓝同学，找一下〔城市＋具体店名或完整地址〕，在地图上展示。”
