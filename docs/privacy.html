隐私政策 (Privacy Policy)

更新日期：2026年8月18日 | 生效日期：2026年8月18日
核心承诺：《听记》（VoiceContext）是一款遵循 Local-First（本地优先） 设计原则的端侧离线语音记录应用。原始录音、转写和声纹处理均在您的设备本地完成；我们不运营收集这些内容的业务服务器，也不会出售或将其提供给广告、分析或其他第三方。

1. 我们如何处理您的数据

1.1 麦克风与音频录制

当您在应用内或通过桌面小组件主动发起录音时，应用会请求麦克风权限（NSMicrophoneUsageDescription）。录制的音频文件将以 AAC 格式保存在您 iPhone 的私有沙盒目录下。未经您的明确主动导出操作，音频文件绝不离开您的设备。

1.2 本地离线语音转写与声纹分析

应用内置端侧本地推理引擎，所有语音转文字、说话人聚类（声纹分析）均 100% 在您的设备芯片上本地计算完成，计算过程无需连接互联网，亦无数据外传。

1.3 导入外部音视频

当您使用系统照片选择器（PhotosPicker）或文件选择器导入音视频时，应用仅在本地临时抽取音轨并进行转写，绝不会修改或上传您的原始相册媒体内容。

1.4 可选录音地点

只有当您主动开启“录音时自动记录地点”时，应用才会请求“使用 App 期间”的定位权限。每次录音仅获取一次当前位置，并将其转换为地点地址后保存到该条录音的元数据。您可以关闭此功能，并可在录音详情中编辑或清空地址。地址不会发送到我们的业务服务器；地点地址解析可能使用 Apple 的系统定位与地理编码服务，并受 Apple 适用条款和隐私政策约束。

2. 数据存储与同步

2.1 本地存储

所有的日常笔记、时间线文档、说话人绑定数据均保存在本地沙盒或公开的“文件”App VoiceContext 目录中。您可以在任何时候手动删除或导出这些数据。

2.2 可选的 iCloud 同步

若您在设置中主动开启了 iCloud 同步：

  • 仅会同步您选择的结构化文本文档（Markdown / JSON，可能包含您选择保留的录音地点元数据）至您的个人私有 iCloud 账户。
  • 声纹特征数据在经过 AES-GCM 强加密后进行备份。
  • 原始音频文件永远不会上传至公开 iCloud Drive。
  • 同步由 Apple 官方 iCloud 基础设施承载，开发者无法访问您的 iCloud 存储内容。

3. 第三方 SDK 与跟踪

《听记》不包含任何第三方广告 SDK、用户行为追踪 SDK 或数据分析埋点工具。我们不使用 IDFA（广告标识符），不进行跨应用跟踪。

4. 权限使用说明

  • 麦克风权限 (Microphone)：仅用于用户主动开始的会议、访谈或语音记录。
  • 定位权限 (Location When In Use)：仅在您开启“录音时自动记录地点”后，用于为当前录音添加地点地址；关闭或拒绝后不影响录音和转写。
  • 后台音频模式 (Background Audio)：用于支持在 App 退至后台或手机锁屏状态下继续平稳录音与播放。

5. 您的权利

您对自己的数据拥有完全的控制权。您可以随时：

  • 在 App 内一键删除单条录音或清空历史记录。
  • 关闭录音地点记录，并编辑或清空已保存的地点地址。
  • 在 iOS“设置”中随时撤销麦克风权限。
  • 卸载 App 将同时清除本地沙盒中的全部私有数据。
