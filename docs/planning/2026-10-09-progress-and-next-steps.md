## 下一步顺序与验收门槛

### 第一阶段：补齐已交付能力的验收

复用 TINGJI-21，补齐专用测试列表的新增 / 编辑 / 完成恢复 / 删除、权限拒绝 / 撤销恢复、只读 / 外部修改及录音中跨 Tab 操作；分别记录通过、失败、阻塞、未测。通知到达仅验证已有系统事项；本地通知未实现时据实记录。

新增两项明确验证任务，避免被完整 AI 工程依赖阻塞：

1. 已有录音反馈回归：按[真机方案](../testing/recording-ai-actions-device-test-plan-2026-10-03.md)验证改名保存 / 取消 / 空值 / 重开、一键启动 / 拒绝权限后恢复、播放与暂停拖动 / 缺口 / 发言人筛选、地点关闭 / 拒绝仍可录音。输出逐项矩阵；通过后再关闭相应 TINGJI-7、10、13、14。
2. 本地事项验收：系统权限拒绝时 UI / Agent 可创建、读取、修改、完成、重开恢复；核对唯一会议日程、未安排 → 补日期不重复、两入口冲突、冷启动链接与锁屏隐私、录音就绪 / Sheet 交接、删除解绑 / 重试不复活、筛选保存及权限恢复。本地通知和系统同步不冒充已经具备。

真机运行遵守 AGENTS.md：必须获得该次运行明确授权，禁止模拟器。当前计划登记不代替运行授权。使用专用数据，避免操作私人日历和提醒。

### 第二阶段：可信文稿、固定输入与产物

先收敛 D01 / D02 / D04 / D05 / D06（TINGJI-31～35）评审结论，再冻结 C00（TINGJI-36）。复用已确认 DESIGN.md；本轮不创建或启动新原型。新增交互沿用现有录音详情、更多菜单、聊天草稿和产物 Sheet，补正常 / 空 / 加载 / 失败 / 离线 / 权限状态及无障碍，不重建录音器、聊天执行器或待办首页。

交付顺序：

- C01 / C02（TINGJI-38、39）：补候选 / 可恢复校对历史、真实完整性与静音 / 有声空识别；与 T01（TINGJI-51）用实际生产路径证明旧稿不丢失。
- C03 / C04（TINGJI-40、41）：固定选定 revision / bytes / hash、关联真实聊天发送与处理状态、正式 manifest 和兼容旧文件 / 用户 Skill。与 T02（TINGJI-52）验证升级与旧数据。
- C12（TINGJI-49）：受管原文、输入快照、历史 / 候选和生成物的删除墓碑与迟到回调防复活；可独立完成，不等待行动关联。

门槛：固定输入不可混读新版；失败 / 取消 / 迟到输出不得伪装成完成；用户改稿与旧产物可恢复；删除后不重建受管资料。Schema 参考向量通过不能替代这些证据。

### 第三阶段：最小纪要与行动闭环

依赖上一阶段：

1. C05 / C06、T03（TINGJI-42、43、53）：先完成纪要、尾段 / 跨段覆盖、原文引用、旧版本结果与真实失败 / 处理中状态，暂不等待导图。
2. C09 / C10 / C13、T04（TINGJI-46、48、50、54）：具体行动 payload 确认、持久幂等与结果不明恢复、来源回跳 / 删除。优先使用已确认的本地 Yima 来源；旧系统目标按相应权限与确认契约管理，不能默默改写目标。
3. 系统事项相关 C11 / T05（TINGJI-47、55）继续补列表 ID、独立 alarm、真实执行点权限与实际回读。与本地 `yima_items` 区分，并在 C00 中明确路由。
4. TINGJI-22 做分段验收：已有桥接路径可先验证；正式 P0 闭环在依赖就绪后完成录音 → ASR / 校对 → 固定输入 → 纪要 → 行动确认 → 实际保存 → 来源回跳。系统镜像 / 导图尚未实现时不计为通过。

门槛：没有选中或确认则不创建；重试 / 重启不重复；日期与负责人不编造；部分成功只重试失败项；保存成功与通知 / 系统同步结果独立。

### 可并行推进：本地定时通知

登记独立需求，当前为 Backlog：先定义本地通知时间、授权 / 拒绝 / 撤销、修改 / 完成 / 删除后的取消与重排、重启恢复、和将来系统镜像的去重策略，再实现。不得把 due 自动当 alarm，不默认已有系统提醒会为本地事项通知。

依赖本地核心能力和通知契约；本地通知可以独立交付，不要求先实现双向同步。验收需有真机真实到达及修改 / 完成 / 删除不遗留旧通知的证据。

### 后续阶段：系统接入与 P1

先完成一个可评审的系统接入决策：仅导出还是双向同步、账户 / 列表精确绑定、更新 / 删除冲突、断连与结果不明恢复、通知去重；待 Human 决策，不默认双向。

方向确认后才拆系统镜像 / 同步实现任务。保留已有系统列表，不按同名自动认领或全量复制。本地成功而系统失败仍保留本地结果。

P1 导图 TINGJI-26 / 37 / 44 / 45 在可信输入与产物成熟后独立推进，不阻塞 P0。外部知识库 TINGJI-17、免手动密钥 TINGJI-15、首批反馈的实时度 / 准确率与安装体验继续保留为候选或待验证，不因本轮提交关闭。

### 发布门槛

在上述能力之外，补历史数据 / 购买 / iCloud / Widget 升级、完整 Agent 工具和音频连续性压力回归、深浅色 / Dynamic Type / VoiceOver / Reduce Motion。测试通过后再准备当前融合版的发行候选和 TestFlight / 商店材料；本轮不宣称版本发布。
