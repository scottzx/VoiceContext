# 共用 Agent 运行时与配置策略

更新：2026-10-18。用户明确要求：小蓝和 Yima 共用执行引擎，差异集中在配置/策略；复杂任务沿用 `spawn_subagent`，子任务 notice 二次唤醒主会话，不转交到 Yima 主会话。

## 目标与范围

保持独立 Agent 身份、SOUL、历史和记忆配置，复用现有模型调用、工具循环、存储、上下文压缩和 notice 队列。运行时不根据小蓝/Yima 身份、语音 source 字面值选择行为。语音采集/胶囊/即时应答及页面授权由应用适配层继续负责。

移除上一轮专用的 `delegate_to_yima`、`deliver_to_xiaolan`、受托主会话上下文及其状态保护分支。已有身份与历史保持，不回滚数据。独立语音和会议语音使用各自会话，不新增前端或改变现有胶囊。

## 配置和运行边界

新增通用 `AgentRuntimePolicy` 与集中注册表。应用在启动时注册工具、角色/交互配置及私有身份可见性；共用引擎只读取策略，不知道具体角色名称。配置描述：工具策略覆盖及白名单、notice 可用工具、答复交付与一次补交付、是否允许精简模式/自动朗读、无界面运行、忙时拒绝、页面授权和提示词构建。既有普通聊天行为使用默认策略。

策略为当前应用的类型化配置，不新增编辑页面、数据库格式或对外 DSL。新增另一套身份/入口只需注册配置，验收以任意第三身份/第三 source 的同类策略为证，避免把角色判断简单改名藏入引擎。

执行授权与页面授权分别绑定。宿主可用 `executionGeneration` 提供当前请求代次，Runner 在实际执行前捕获为 `toolExecutionGeneration`，通知恢复时清空；故事工具据此拒绝过期请求，锁屏不依赖页面可见性。导航/预览仍使用既有前台解锁与导航代次。事项详情的独立打开入口同时检查 `allowsItemPresentation`、实际前台状态及策略要求的导航绑定，后台数据操作继续可用。

每个显式 agentId 的新会话从真实 AgentProfile 读取模型/记忆偏好，运行请求不提供 agentId 时保留持久化归属。执行子会话仍由通用 executor 权限约束，不能继承语音的页面/公开答复权。

子会话的默认策略关闭自动朗读；缓存重载后继续恢复其 source，避免后台结果绕过父会话直接发声。普通聊天的自动朗读偏好保持。记忆提示按实际回合工具与策略生成，notice 或仅答复回合不会声称能使用已隐藏的记忆工具。

## 子任务和二次唤醒

1. 明确指令进入小蓝会话；简短原生操作直接执行，复杂工作使用现有 `spawn_subagent`（现有专用云能力仍按其原工具定义提供）。
2. 回执只确认已开始；主会话实际调用 `answer_user(text)` 后结束当前轮并恢复待机。
3. 既有 SubagentCoordinator 持久化终态并向父会话发送 `async_task_notice`，经原 notice 队列去重。
4. 通用 notice 适配钩子预约当前可用的语音交付，按宿主规则核对模式、录音和请求代次；用户已开启的独立语音在后台也可交付，只对有效状态二次唤醒，不播放新的“收到”。
5. notice 回合只允许 `answer_user`，交付真实完成/失败/停止结果，不重新派发、不修改事项、不抢页面。
6. 关闭、暂停或前台手动换页时保留原会话结果，不恢复开麦或抢屏；锁屏仅撤销页面权，已开启的独立语音继续执行与交付。后续明确前台请求可按现有直属子会话产物范围展示图片/HTML。

不改变子任务 ID、真实父子归属、模型继承及 task delivery 路径；恢复工具控制本来支持的查询/跟进/停止，不再把 A2A relay ID 冒充子任务 ID。

## 工具和提示词

角色提示词及语音环境说明移出通用 OrchestratorPrompt，由应用配置构建。公共身份拼装使用通用身份选项控制环境与配置提示，不包含小蓝/Yima 分工字面值。原有普通身份文本维持一致。

公开答复工具本身使用宿主绑定和单次交付判定，来源校验读取配置能力，不写死语音 source。执行分派同时检查真实策略与已注册工具，伪造名称不能扩大权限。保留一次仅答复恢复，禁止为补发文字重做业务。

## 验收、兼容与交付

- 共用 VM、Runner、notice 管理和提示词拼装中没有小蓝/Yima 专用判断或专线字段。
- 任意第三身份/source 可注册同类策略，完整支持工具过滤、答复及 notice，无需修改引擎。
- 原生语音会话、子任务父子关系与 AgentProfile 归属正确；模型、记忆与历史不互相串用。
- 真实 spawn → 持久化终态 → 去重 notice → 二次唤醒 → `answer_user` 通过主机边界测试。
- 普通 Yima、executor、录音互斥、导航/产物、胶囊和即时应答回归；generic iOS 签名构建及当前设备安装分别记录。
- 不使用 Simulator，不自动启动设备 App。真实语音及模型选工具仍需交互验收。

无新增 UI/UX 决策，沿用 DESIGN.md 已批准的拓展入口和单色胶囊；原型任务不适用。PM 服务本轮查询仍返回 127.0.0.1:38080 拒绝连接，先保存本设计及验收，不伪造项目项或功能树状态。
